# Proofs

[Model and theorem](model.md) defines the access interfaces, the fixed physical query budget, and the block family characterized by equality of all proper temporal marginals.

[Search construction](construction.md) gives the two diffuser schedules, derives the exact conditional search probability, and charges phase-only certification and the linear fallback.

[Adaptive converse](converse.md) bounds the progress of arbitrary interleavings with unrestricted workspace, including the cost of partial blocks.

[Hidden boundaries](hidden-boundaries.md) removes the need to know the initial block offset and extends the conclusion to a stationary random offset.
