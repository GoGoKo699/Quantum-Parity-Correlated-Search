# Oracle and query budgets

Fix an integer $`N\ge3`$. The input is either empty or has one marked index $`x\in[N]`$. The algorithm returns the marked index or `none`. It must succeed with probability at least $`9/10`$ on each input. Error probabilities average over oracle faults and algorithm measurements and randomness.

The ordinary phase oracle on a marked input is $`O_x=I-2|x\rangle\langle x|`$. The bit oracle is $`|j,b\rangle\mapsto|j,b\oplus[j=x]\rangle`$. The empty-input oracle is the identity in both interfaces. A slot with activation sign $`s_j=+1`$ applies the oracle and a slot with $`s_j=-1`$ applies the identity. The signs are unobserved, independent of the input and of the algorithm's actions, and unaffected by measurement and preparation. There is no flag, clean membership test, or reset. The algorithms use the phase interface. Controlled phase access is allowed in the lower bound as a stronger interface and also covers ordinary bit access via phase kickback.

Consecutive issued physical calls occupy consecutive slots. Waiting without calling does not advance the process. At most one call is issued in each slot. The fixed worst-case budget includes unsuccessful trials, all certificate calls, and every dummy call. Standard query-independent operations and algorithm-owned ancillas are ideal. The cost here is the number of issued queries.

## The parity law

Within each length-$`L`$ block, $`L\ge3`$, the activation signs are distributed as

```math
p_\kappa(s_1,\ldots,s_L)
=2^{-L}\left(1+\kappa\prod_{j=1}^{L}s_j\right),
\qquad -1\le\kappa\le1.
```

Different blocks are independent. The parameters $`N,L,\kappa`$ are supplied. In the aligned model the first call begins a new block. In the hidden-boundary model the first call has an unknown fixed offset within a block, and the guarantee holds for every offset. One can define the signs on a two-sided sequence of independent blocks and then choose the start offset uniformly once to obtain a stationary activation process.

The whole-block parity has mean $`\kappa`$. To generate a block, draw $`L-1`$ independent fair signs, keep their running product, and select the last sign so the final product is $`+1`$ with probability $`(1+\kappa)/2`$. This needs one parity bit and a clock specifying position in the block.

## Proper-subset equality

Marginalizing any one slot cancels the product term. Every proper-subset activation marginal is therefore exactly uniform. Conversely, for a distribution on $`L`$ signs, the Walsh expansion is

```math
p(s)=2^{-L}\sum_{A\subseteq[L]} \mathbb E\!\left[\prod_{j\in A}s_j\right]
\prod_{j\in A}s_j .
```

Uniformity on proper subsets forces the coefficient of every nonempty proper subset to vanish. Hence the displayed one-parameter family is exhaustive among such block laws.

An experiment restricted to inspecting a proper subset of slots in every block sees exactly the independent half-omission process. This holds for arbitrary ancillas, interleaved operations, and adaptive choices on the inspected slots. Just before each inspected sign is used, its conditional distribution given the previously inspected signs in its block is fair, because the enlarged inspected set is still proper. Conditioning on the algorithm's accessible history preserves this conclusion since, on that branch, the history is generated by those signs and the input-independent controls. Inductively this gives equality of the final outcome laws for every fixed marked or empty input. Slots outside the inspected subsets contribute no oracle action to the experiment. In particular, all experiments on fewer than $`L`$ slots agree even if their slots straddle block boundaries.

## Optimal resource

Uniformly in all stated parameters, the aligned and hidden-boundary models have optimal quantum query cost

```math
Q(N,L,\kappa)=
\Theta\!\left(\min\!\left\{N,\ L\left[\sqrt N+N(1-|\kappa|)\right]\right\}\right).
```

The upper bound holds with ordinary phase access and zero false positives. The lower bound allows controlled phase access, arbitrary adaptive interleavings, and unrestricted workspace. The classical randomized query complexity with the bit interface is $`\Theta(N)`$. A noiseless classical bit oracle can simulate this process, proving the lower bound by ordinary unstructured search. Four full scans furnish the upper bound because, for the true target, its four queried slots cannot exhaust any block, so their activation bits are jointly fair and independent.
